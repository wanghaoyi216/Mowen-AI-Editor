# 产品设计文档

## 1. 产品定位

本产品是一个面向小说策划与创作流程的 AI 原生编辑器，不只是“文本补全器”，而是一个具备规划、资料抽取、角色建模、剧情编排、章节生成、关系图谱管理与过程记忆能力的创作工作台。

## 2. 核心用户

1. 长篇小说作者
2. 网文工作室
3. 需要批量策划故事的内容团队
4. 需要结构化管理故事资产的创作者

## 3. 核心能力

1. 小说项目管理
2. 热点题材探索
2. 联网资料研究与信息抽取
3. 角色卡自动生成
4. 角色关系图谱管理
5. 世界观与设定管理
6. 主线/支线剧情设计
7. 章节规划与章节生成
8. AI 执行计划与日志可视化
9. 记忆沉淀与复用
10. 多任务流状态拆分

## 4. MVP 范围

### 必做

1. 项目创建与配置
2. 角色管理
3. 角色关系图谱
4. 剧情线管理
5. 章节规划
6. 章节生成
7. AI 任务执行记录
8. 资料库与抽取结果存档

### 后续增强

1. 风格模仿与个性化文风
2. 多 Agent 协同
3. 自动一致性校验
4. 商业化模板与行业预设
5. 大纲到长篇自动扩写

## 5. 页面设计

### 5.1 仪表盘

- 展示项目概览
- 最近 AI 任务
- 待处理问题
- 当前章节进度

### 5.2 项目工作台

- 项目基本信息
- 类型、题材、目标读者、篇幅目标
- 写作规则与禁忌

### 5.2.1 热点探索中心

- 当前热门题材榜单
- 热门标签组合
- 爆款结构参考
- 联网分析结果
- 可转化为项目设定的候选方向

### 5.3 角色中心

- 角色卡列表
- 角色详情
- 角色成长弧线
- 角色关系图谱入口

### 5.4 图谱中心

- Neo4j 关系图可视化
- 人物关系
- 阵营关系
- 冲突关系
- 剧情事件关系
- 章节影响关系
- 点击节点联动详情面板

### 5.5 剧情设计中心

- 主线
- 支线
- 世界观设定
- 时间线
- 冲突设计

### 5.6 章节工作台

- 章节规划列表
- 章节详情
- AI 生成草稿
- 人工编辑区域
- 版本记录

### 5.7 AI 执行中心

- 任务计划
- 推理日志
- 工具调用记录
- 抽取结果
- 错误与修正建议
- 任务流分类
- 按项目/章节/模块过滤

## 6. 设计风格建议

1. 避免通用后台风格，采用“创作工作台”视觉语言。
2. 以暖色纸张质感结合深色墨迹对比，突出写作沉浸感。
3. 图谱、时间线、章节卡片要有明显层次。
4. UI 以桌面优先，同时兼顾移动端查看。

## 7. 关键非功能要求

1. 轻量级部署
2. 模块化架构
3. Prompt 可配置
4. 日志与记忆可追踪
5. 输出可回溯
