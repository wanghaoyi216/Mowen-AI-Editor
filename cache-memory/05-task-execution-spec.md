# 详细任务执行方案书

## 1. 总目标

逐步交付一个可运行、可扩展、可沉淀知识资产的智能 AI 小说编辑器。

## 2. 当前执行顺序

### Step 1: 项目基线搭建

- 建立前后端目录
- 建立 `cache-memory`
- 输出产品/数据库/API/业务文档

### Step 2: 后端核心模型

- 建立 FastAPI 项目结构
- 定义配置系统
- 定义 SQLAlchemy/SQLModel 数据模型
- 建立数据库初始化逻辑
- 建立健康检查与项目 API

### Step 3: 图谱层

- 定义 Neo4j 客户端
- 定义角色关系写入与查询接口
- 定义图谱同步策略

### Step 4: AI 任务编排层

- 定义任务实体
- 定义 Planner
- 定义 ReAct Executor
- 定义 Extraction Pipeline
- 定义 Memory Updater

### Step 5: 前端工作台

- React 路由和布局
- 项目概览页
- 角色中心
- 图谱页面
- 剧情设计页
- 章节工作台
- AI 日志页

### Step 6: 联调与沉淀

- 建立端到端基础流程
- 补充问题文档
- 补充经验文档
- 更新下一个 AI 提示词

## 3. 每个功能的执行模板

1. 明确功能目标
2. 查找已有上下文
3. 梳理输入输出
4. 设计数据结构
5. 设计 API 或组件
6. 编写实现
7. 本地验证
8. 记录问题、解决方案、经验、后续优化

## 4. AI 执行规范

所有 AI 子任务都要遵循下面的 Prompt 约束：

1. 必须先输出计划，再执行。
2. 必须采用 ReAct 风格思考，但对外只暴露必要结果。
3. 必须进行信息抽取，将可复用结论结构化保存。
4. 每完成一步，都更新记忆和任务日志。
5. 不允许跳过约束检查直接生成长文。

## 5. 功能优先级

P0:

1. 项目管理
2. 角色管理
3. 图谱关系管理
4. 剧情线管理
5. 章节规划与生成

P1:

1. 联网研究
2. 任务日志与回溯
3. 章节修订与版本管理

P2:

1. 自动一致性校验
2. 多 Agent 协同
3. 风格控制增强

## 6. 本轮执行项

1. 建立项目结构
2. 初始化前端
3. 初始化后端
4. 落第一批核心 API 和模型
5. 建立记忆与日志模板
