# 总体任务执行总计划

## 项目目标

构建一个轻量级的智能 AI 自动小说编辑器，支持以下能力：

1. AI 联网搜集写作相关资料并沉淀为项目知识。
2. AI 使用 ReAct + Plan-and-Execute + Extraction 模式完成规划、推理、抽取与生成。
3. 设计小说世界观、人物角色、人物关系、主线、支线、章节规划。
4. 使用 Neo4j 管理角色关系和剧情关系图谱。
5. 使用 React + FastAPI 提供前后端一体化的创作界面。
6. 形成持续可复用的 `cache-memory` 文档资产，供后续 AI 接续执行。

## 执行原则

1. 先后端逻辑，后页面表现。
2. 先结构化建模，后生成式写作。
3. 先定义输入输出边界，后接入 AI Agent。
4. 每完成一个功能，沉淀问题、经验、提示词和下一步计划。

## 分阶段计划

### Phase 0: 项目基线

- 明确产品边界
- 明确技术栈
- 明确 AI 执行模式
- 初始化文档与代码骨架

### Phase 1: 核心数据建模

- 设计关系型数据库表
- 设计 Neo4j 图谱节点与边
- 设计章节、角色、剧情、任务、资料、记忆模型

### Phase 2: 后端服务

- 设计 API 文档
- 设计 AI 编排服务
- 设计联网检索与抽取服务
- 设计写作生成流水线

### Phase 3: 前端工作台

- 项目总览页
- 小说项目管理页
- 角色与关系图谱页
- 剧情设计页
- 章节写作页
- AI 执行与日志页

### Phase 4: AI 执行闭环

- 任务计划器
- ReAct 推理器
- Extraction 抽取器
- 记忆更新器
- 输出质检器

### Phase 5: 可持续迭代

- 日志沉淀
- Prompt 版本管理
- 经验归档
- 优化项回收
