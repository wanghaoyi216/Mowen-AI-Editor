# 全面系统模块设计 v2

## 1. 产品目标升级

目标不再是单一的“小说编辑器”，而是一个完整的 AI 小说自动创作系统，具备：

1. 自动搜集网络信息资料
2. 自动进行题材与热点探索
3. 自动规划故事世界观与角色体系
4. 自动设计人物关系与剧情关系图谱
5. 自动执行 ReAct 工作流
6. 自动生成章节规划和章节正文
7. 自动沉淀记忆、日志、问题、经验
8. 自动更新下一轮工作计划

## 2. 模块总览

### 2.1 项目中心

用于管理不同小说项目。

### 2.2 题材/热点探索中心

用于联网研究当前热门题材、叙事模式、读者偏好、爆款标签、参考作品。

### 2.3 资料研究中心

用于收集背景资料、设定参考、时代信息、职业知识、场景知识。

### 2.4 世界观中心

用于管理世界规则、地理、历史、阵营、能力体系、道具体系。

### 2.5 角色中心

用于管理角色卡、人物成长弧、动机、秘密、关系、角色状态。

### 2.6 图谱中心

用于展示和管理 Neo4j 前端图谱：

1. 人物关系图
2. 剧情事件图
3. 阵营关系图
4. 地点关联图
5. 章节影响图

### 2.7 剧情设计中心

用于管理主线、支线、冲突、反转、时间线、伏笔与回收。

### 2.8 章节工坊

用于规划章节结构、节拍、POV、目标、冲突，并执行生成。

### 2.9 AI 任务流中心

用于详细分开管理不同任务流：

1. 热点探索任务流
2. 资料研究任务流
3. 世界观设计任务流
4. 角色设计任务流
5. 剧情规划任务流
6. 章节写作任务流
7. 一致性检查任务流
8. 修订重写任务流

### 2.10 记忆与知识库中心

用于沉淀长期记忆、项目规则、风格规范、问题经验、复用模板。

## 3. 任务流分层

每个任务流都必须独立记录：

1. 所属小说项目
2. 所属模块
3. 所属章节或剧情线
4. 工作阶段
5. ReAct 状态
6. 计划版本
7. 工具调用记录
8. 结果摘要
9. 失败原因
10. 记忆提取结果

## 4. Neo4j 前端展示要求

前端必须支持：

1. 根据项目切换图谱
2. 根据图谱类型切换视图
3. 根据章节范围过滤事件节点
4. 根据角色筛选关系边
5. 查看节点详情与关系详情
6. 支持点击跳转到角色/章节/剧情详情

## 5. 自动创作闭环

### 输入层

1. 用户初始设定
2. 网络资料
3. 热点分析
4. 项目规则
5. 历史章节与记忆

### 推理层

1. Planner
2. ReAct Executor
3. Extractor
4. Consistency Checker
5. Memory Updater

### 输出层

1. 角色
2. 图谱
3. 剧情线
4. 章节规划
5. 章节正文
6. 修订建议

## 6. 系统页面建议

1. Dashboard
2. Projects
3. Trend Explorer
4. Research Library
5. Worldbook
6. Characters
7. Graph Studio
8. Plot Studio
9. Chapter Studio
10. Task Flows
11. Memory Center

## 7. 架构结论

该项目最终应被理解为：

“一个围绕小说项目进行资料研究、结构化策划、图谱建模、AI 工作流执行与章节创作的 AI 原生创作系统。”
